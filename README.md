# CoffeeStream

CoffeeStream is a university web project designed to help users find where their favorite movies and TV shows are available to stream across multiple services.

Instead of checking several platforms manually, users can quickly see which streaming service offers the content they want.

## Features

- Search for movies and TV shows
- Track streaming availability across multiple services
- Simple and user-friendly interface
- Database-backed content tracking
- Designed as a full-stack web application

## Tech Stack

- PHP
- JavaScript
- HTML/CSS
- MySQL / MariaDB

## Project Overview

This project was created as part of a university assignment and focuses on solving the common problem of content being spread across different streaming platforms.

## How to Run

1. Clone the repository
2. Place the project in your local web server directory (e.g. XAMPP / WAMP / MAMP)
3. Import the database if a SQL file is included
4. Configure database credentials in the project configuration files
5. Start the local server and open the project in your browser
